# QA_54_demowebshop

## Project Description
This project is created for testing the Demo Web Shop website.
Учебный проект по автоматизированному тестированию веб-приложения Demo Web Shop

Website: Тестируемое приложение: https://demowebshop.tricentis.com/

## Tools Используемые технологии:
- Python — язык программирования
- Selenium WebDriver — автоматизация браузера
- PyCharm - программа для Python.
- Git / GitHub — система контроля версий
- Pytest — фреймворк для тестирования
- Google Chrome — браузер для запуска тестов

## Test Areas
- Home page - Тесты главной страницы магазина
- User registration - Тесты регистрации
- User login - Тесты входа в аккаунт
- README.md - Описание проекта
- requirements.txt - Список необходимых Python-библиотек
- .gitignore - Файлы, которые Git не должен сохранять
